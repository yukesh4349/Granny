# API Documentation

REST endpoints provided by NestJS backend:
- `/api/auth` - Authentication and session management
- `/api/users` - Senior & Caregiver profile management
- `/api/conversations` - Conversational history and voice synthesis dispatch
- `/api/memory` - Personal story & memory logging
- `/api/health` - Health metrics and medication schedules
- `/api/games` - Cognitive brain game score tracking
- `/api/family` - Caregiver and family updates
